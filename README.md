## Product Vision & Overview
Our product aims to provide an intelligent, AI-assisted system architecture platform that integrates local LLMs (via LM Studio/OpenAI API) with a modern web interface. By leveraging FastAPI and MBSE (Model-Based Systems Engineering) principles, the system streamlines workflow automation, requirements tracking, and interactive analysis for complex systems engineering tasks.
